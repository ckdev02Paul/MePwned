MEPWNED DOCUMENTATION

Security Assessment Toolkit · Documentation

HOW TO USE

1Fill the Global Config bar (top) with your target URL, session cookie, and CF clearance (if needed). These auto-fill into all tools.
2Select a tool from the sidebar. Its form will appear with pre-filled defaults.
3Adjust parameters as needed. Mode-specific fields will show below the mode dropdown.
4Click ▶ RUN. Output streams in real-time to the terminal panel. Use ■ KILL to abort.
5For EXECVEIL: after deploying a shell (POC 5), use the ⚡ CONNECT panel to start an interactive shell session.
⚠ All tools are for AUTHORIZED security assessment only. Unauthorized use violates RA 10175.

GLOBAL CONFIGURATION

TARGET URL — The base URL of the target application (e.g. http://es_ldcu.dev or https://assure-prod.essentiel.ph)

SESSION COOKIE — A valid laravel_session cookie. Obtain by logging in normally and copying from browser DevTools → Application → Cookies.

CF CLEARANCE — Required only if Cloudflare is protecting the target. Copy from browser cookies after passing the challenge.

Global values auto-fill into all tools marked with the "global" badge. They persist in localStorage across browser sessions.

TIPS

• Most tools marked NO AUTH work without any session cookie — just a target URL.

• Output streams in real-time. Progress bars (from tqdm) animate in place.

• Use VENOM mode 3 first to get all user credentials, then OVERLORD mode 8 to auto-login.

• After EXECVEIL POC 5, use the shell connect panel for persistent interactive access.

• ORACLE + TRASHFIRE cover most data exfiltration needs without authentication.
